Stop parsing LLM JSON with regex and hope. Use structured outputs 👇

→ Asking for JSON in the prompt works until one response adds a sentence or drops a field
→ Structured outputs constrain the response to a JSON schema you send
→ On Amazon Bedrock you can send a JSON schema as the output format, or set strict: true on a tool definition
→ Use enums and required fields so there's nothing left to guess
→ Valid JSON can still be wrong, so keep validating business rules
