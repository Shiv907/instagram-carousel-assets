You ship a new tool on your MCP server on Monday. Does your agent registry know about it on Tuesday?

If that catalog is only updated by hand, agents end up reading stale tool schemas. AWS just published a push-based way to keep AWS Agent Registry records fresh, and it's simpler than I expected.

The flow:
CloudTrail sees UpdateAgentRuntime. EventBridge routes it. A Lambda calls tools/list on the server, diffs the result against the record, and updates the record only if something actually changed.

My favourite part is that the update drops the record back to Draft until a curator approves it. So the automation keeps things fresh, but it can't skip review.

Read the limits before you copy it. It only updates records that are already APPROVED, and CloudTrail delivery takes about 5 to 15 minutes.

Save this if you run MCP servers at scale. Does anyone on your team review catalog changes today? Tell me in the comments.
