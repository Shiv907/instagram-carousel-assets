Is RAG dead now that models can read huge inputs? Short answer: no. The RAG series finale 👇

→ Long context wins for one long document or a small, fixed set of files
→ RAG wins for large or changing document sets, per-user permissions and cited answers
→ Long context means paying for every token on every question. RAG sends only what's relevant
→ The practical answer is often both: retrieve the right documents, then send whole sections
→ Cache the stable parts of the prompt to cut repeat latency and input token costs (Bedrock prompt caching)
